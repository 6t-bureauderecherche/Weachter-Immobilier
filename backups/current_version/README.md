# Sauvegarde de l’application avant le passage aux parcelles

Cette copie conserve la version avec les mailles de 25 m et les tuiles vectorielles : `app.py`, les ressources du logo, les données de mailles et leurs GeoParquet, les scripts de préparation et le dossier complet `static/tiles/`.

Pour restaurer cette version, recopier `app.py`, `assets/`, `data/` et `static/tiles/` à la racine du projet.
